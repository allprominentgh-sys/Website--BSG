# ALL PROMINENT GHANA

A Ghana-focused marketplace and advertising platform starter.

## Included in this version
- ALL PROMINENT GHANA branding
- Marketplace homepage and listings
- Multi-currency: GHS, USD, EUR, GBP, CNY
- Google and Apple OAuth login buttons
- Email/password login
- Post-an-ad form with optional video upload field
- Advertising page
- Seller/account dashboard
- Supabase SQL schema for listings, stores, messages, favorites, reviews, video ads and analytics

## Next implementation step
Create a Supabase project, run `supabase.sql`, add `.env.local` from `.env.example`, enable Google and Apple providers, then connect listing/video storage and real CRUD.

Run locally:

npm install
npm run dev

Then open http://localhost:3000
